# 🎉 PrizeMania – Lucky Draw Web Application

PrizeMania is a database-driven web application developed as part of my Computing coursework. The project simulates an online lucky draw platform where users can register, purchase tickets, and participate in monthly prize draws, while administrators manage the draw and publish winners.

This project helped me gain hands-on experience in building a full-stack web application, designing relational databases, and following a structured software development process.

## ✨ Features

### User
- Register a new account
- Log into the system
- Purchase lucky draw tickets
- View available prizes
- View monthly winners

### Administrator
- Secure administrator login
- Generate winning tickets
- Select and publish winners
- Manage the lucky draw process

## 🏗️ System Workflow

```text
User Registration
        ↓
     User Login
        ↓
 Purchase Lucky Draw Ticket
        ↓
 Store Purchase in Database
        ↓
 Administrator Generates Winner
        ↓
 Winner Saved to Database
        ↓
 Winner Displayed on Homepage
```

---

## 🗄️ Database Design

The application uses a relational MySQL database consisting of the following main tables:

- User
- Admin
- Bank
- Ticket
- Ticket Category
- Purchase
- Winner

The database was designed using an Entity Relationship (ER) Diagram before implementation.
